# Backend

API, Save/Load, kiểm tra điều kiện thắng/thua và chuyển trạng thái NPC sẽ nằm ở đây sau khi chốt đặc tả. Chưa có mã dịch vụ hoặc gameplay.

Đọc [Scope Baseline](../docs/scope-baseline-demo-a-v1.0.md), [System Design](../docs/system-design-demo-a.md) và [hợp đồng Save/Load](../docs/save-load-contract-demo-a.md). Backend là nguồn quyết định trạng thái; schema trong `database/` là bản nháp thiết kế.
